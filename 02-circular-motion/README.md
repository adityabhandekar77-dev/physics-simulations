# Circular Motion

## Physics

Circular motion occurs when an object moves along a circular path.

### Key equations

- Tangential speed: v = r * omega
- Centripetal acceleration: a = v^2 / r
- Angular velocity: omega = 2 * pi / T
- Period: T = 2 * pi / omega

Where:
- r = radius in metres
- v = tangential speed in metres per second
- omega = angular velocity in radians per second
- T = time for one complete revolution in seconds

## Key concept

Even at constant speed, velocity changes because the direction
of motion changes. Centripetal acceleration points toward the
centre of the circle.
